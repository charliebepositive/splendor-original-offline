# 璀璨宝石 · 原版离线

经典基础版 Splendor，中文界面，90 张原版发展卡实拍卡面、10 位贵族。支持 2–4 人本地热座、电脑对手、自动存档、存档导入/导出与完整离线运行。

## 打开

双击 **index.html** 或 **打开游戏.bat** 即可开始。不需要 npm 安装、服务器或网络。

如果希望使用本地浏览器缓存，或浏览器限制本地文件存档，可双击 **启动本地服务.bat**（需要 Node.js），再打开 http://127.0.0.1:8080 。也可执行：

```powershell
node tools/serve.cjs
```

服务器只监听本机 127.0.0.1。这里的本地静态服务不是在线对战。页面显示“全部素材已就绪 · 可离线”后，90 张卡面和规则书均已预缓存，断网也能刷新页面。直接双击文件的方式无需 Service Worker，所有依赖本来就在目录中。

## 已实现

- 原版 90 张确定牌值（40/30/20），按级洗牌与补牌，黄金万能支付。
- 拿三种不同色；仅不足三种库存时少取；同色双拿需库存至少 4。
- 市场/暗牌保留与 3 张手牌上限；黄金耗尽仍可保留。
- 永久折扣、可手动调整的黄金支付、10 筹码上限与自主归还。
- 贵族自动来访，多位可选时人工选择，每回合至多一位。
- 15 分触发最后一轮、同分时已购发展卡较少者胜、共同胜利。
- 2–4 个座位可各选真人/电脑，电脑只用公共信息与自己的保留牌决策。
- 多真人热座交接遮挡。保留牌仅当前真人可见。
- 自动存档、恢复对局、JSON 导入/导出、电脑暂停、中文规则。
- 响应式布局、本地卡面与字体、无 CDN、无在线入口与服务配置。

## 规则与图片

`docs/rules.html` 是中文整理，`docs/Splendor-EN.pdf` 是官方基础版英文规则书。完整链接、卡牌原始元数据与权利说明见 `docs/SOURCES.md`。

**90 张发展卡为原版实体卡照片裁切；贵族和牌背是重绘的界面样式，不是官方插画。** 原项目保存在同级 `pokemon-splendor-main`，未改动。

## 开发与验证

无需构建；直接加载普通 JS，兼容 `file://`。

```powershell
node test/engine.test.cjs
node tools/build-data.cjs
```

测试涵盖规则边界、卡面文件、手牌隐私对 AI 决策的影响、保存完整性与 120 局 2–4 人自对弈。`build-data.cjs` 使用本地元数据重建数据与离线缓存列表，不访问网络。

结构：`js/engine.js` 纯规则，`js/ai.js` 本地电脑，`js/ui.js` 界面，`js/data.js` 卡牌与贵族，`assets/cards` 图片，`sw.js` 全量离线预缓存。
